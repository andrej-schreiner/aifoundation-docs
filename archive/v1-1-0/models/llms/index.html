General-purpose text generation, conversational agents, and reasoning. Most LLMs on AI Foundation Services accept multilingual input and support streaming + tool/function calling.

Token-by-token output via Server-Sent Events. Suitable for low-latency, real-time UI. Function / tool calling (OpenAI-compatible). The model can return structured tool invocations. Accepted values of the reasoning_effort parameter, from the platform model datasheet. "-": no values are published for this model. See the Reasoning Control guide. Where the response reports the number of reasoning tokens in the usage object: completion_tokens_details.reasoning_tokens, usage.reasoning_tokens, or not reported (the model reasons, but the response carries no count). "-": the model has no reasoning. Price per million prompt tokens served from the prefix cache: 15% of the normal input price. T-Cloud-hosted models only — cached pricing for external providers will be added later.
