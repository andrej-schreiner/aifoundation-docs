Shared plans use a monthly token revenue commitment. Usage above it is billed at list prices. Plans differ by throughput (TPM and RPM) and by Premium model access. Premium models such as Claude Opus are included on Professional and Agentic, not on Essential. Enterprise is a custom token commitment and custom rate limits. Create a trial key in the [API Key portal](https://apikey.llmhub.t-systems.net/). A trial key unlocks all models, including Premium. To order a plan, [contact us](mailto:ai@t-systems.com). For reserved hardware, see [Dedicated serving](/plans/dedicated).

## Shared or dedicated

<a id="shared-or-dedicated"></a>

A shared plan is the multi-tenant API behind Essential, Professional, and Agentic. Capacity is pooled, and each plan publishes RPM and TPM ceilings on [Rate limits](/reference/rate-limits). [Dedicated serving](/plans/dedicated) reserves GPU hardware for your contract, including a private model that fits on that hardware.
