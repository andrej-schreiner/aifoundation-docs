AI Foundation Services offers two ways to run models. This page only points at the pages that already describe them. It does not add prices, limits, or SLA figures.

## Shared rate plans

The shared service is the multi-tenant API behind the [rate plans](/plans): Essential, Professional, and Agentic. You call the same OpenAI-compatible endpoint as in the [quickstart](/). Capacity is pooled, and each plan has request and token ceilings. Those ceilings, and the conditions on them, are on [Rate limits](/reference/rate-limits).

Shared hosting is the right starting point for a trial key, a prototype, and steady traffic that fits a published plan.

## Dedicated serving

[Dedicated LLM Serving](/plans/dedicated) reserves GPU hardware for your contract. The dedicated page is where tenancy, model choice, and how to request a quote are written down. Use it when you need hardware that is not shared with other customers, including a private model that fits on that hardware.
