AI Foundation Services runs models in two ways: a shared rate plan, or dedicated hardware.

## Shared rate plans

The shared service is the multi-tenant API behind the [rate plans](/plans): Essential, Professional, and Agentic. You call the same OpenAI-compatible endpoint as in the [quickstart](/). Capacity is pooled. Each plan publishes request and token ceilings on [Rate limits](/reference/rate-limits).

Shared plans suit prototypes and traffic that fits a published plan. Trial keys also run on the shared service.

## Dedicated serving

[Dedicated LLM Serving](/plans/dedicated) reserves GPU hardware for your contract. That page covers tenancy, model choice, and how to request a quote. Use it when you need hardware that is not shared with other customers, including a private model that fits on that hardware.
