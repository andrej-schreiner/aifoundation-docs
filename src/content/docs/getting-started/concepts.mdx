Terms used across these docs. Each one points at the page that already defines the behaviour. Nothing here adds a number.

## Tokens

A token is the unit the API counts. Chat requests set `max_tokens` for how many tokens to generate, and rate limits count tokens per minute. The catalog does not name a tokenizer on this page.

## TPM

Tokens per minute. A shared plan publishes an input TPM and an output TPM per model. The figures and the conditions on them are on [Rate limits](/reference/rate-limits).

## RPM

Requests per minute. A shared plan publishes how many requests you can send per model. Same page as TPM: [Rate limits](/reference/rate-limits).

## Context window

How much text a model accepts in one request, as printed in the catalog (`8K`, `128K`, `1M`, and so on). When the catalog field is empty, these docs say the context window is not published. See [Choosing a model](/getting-started/choosing-a-model).

## T-Cloud

Telekom-hosted models. In the catalog their region is Germany. Prompts for these models are processed as described on [Enterprise Trust](/reference/enterprise-trust). The label in the product is T-Cloud.

## Partner models

Models the API forwards to another provider. In the catalog those regions are Azure or GCP, including a named region such as Sweden Central or `europe-west1`, or worldwide. Data handling for that path is also on [Enterprise Trust](/reference/enterprise-trust).

## OpenAI-compatible

The HTTP API accepts the same client as the OpenAI SDK. The [quickstart](/) sets `OPENAI_BASE_URL` and sends `chat/completions`. It does not mean every OpenAI parameter exists on every model. Check the guide for the call you are making.

## Reasoning effort

The `reasoning_effort` parameter on models whose datasheet lists accepted values. The value list is per model. See [Reasoning](/guides/reasoning).

## Embeddings

A vector for a piece of text, from `POST /embeddings`. Used for semantic search and retrieval. See [Embeddings](/guides/embeddings).
