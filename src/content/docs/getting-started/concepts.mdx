## Tokens

A token is the unit the API counts. Chat requests set `max_tokens` for how many tokens to generate. Rate limits count tokens per minute.

## TPM

Tokens per minute. A shared plan publishes an input TPM and an output TPM per model. The figures are on [Rate limits](/reference/rate-limits).

## RPM

Requests per minute. A shared plan publishes how many requests you can send per model. Same page as TPM: [Rate limits](/reference/rate-limits).

## Context window

How much text a model accepts in one request, as listed in the catalog (`8K`, `128K`, `1M`). See [Choosing a model](/getting-started/choosing-a-model).

## T-Cloud

Telekom-hosted models. In the catalog their region is Germany. [Enterprise Trust](/reference/enterprise-trust) describes how prompts for these models are processed. The product label is T-Cloud.

## Partner models

Models the API forwards to another provider. The catalog regions are Microsoft Azure or Google Cloud: a named region such as Sweden, France, or `europe-west1`, or worldwide. Data handling for that path is on [Enterprise Trust](/reference/enterprise-trust).

## OpenAI-compatible

The HTTP API accepts the OpenAI SDK. The [quickstart](/) sets `OPENAI_BASE_URL` and sends `chat/completions`. Check the guide for the call you are making. Not every OpenAI parameter exists on every model.

## Reasoning effort

`reasoning_effort` on models whose datasheet lists accepted values. The list is per model. See [Reasoning](/guides/reasoning).

## Embeddings

A vector for a piece of text, from `POST /embeddings`. Used for semantic search and retrieval. See [Embeddings](/guides/embeddings).
