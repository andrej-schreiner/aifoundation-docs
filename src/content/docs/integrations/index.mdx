AI Foundation Services exposes an OpenAI-compatible API, which means most frameworks and tools built for OpenAI work out of the box — point the base URL at `https://llm-server.llmhub.t-systems.net/v2` and supply your API key. The pages below cover T-Systems' own coding tools and how to connect a coding tool or IDE plugin.
