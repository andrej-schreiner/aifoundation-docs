AI Foundation Services exposes an OpenAI-compatible API, which means most frameworks and tools built for OpenAI work out of the box — point the base URL at `https://llm-server.ai.t-systems.net/v1` and supply your API key. The pages below cover the most common framework integrations with working setup examples.
