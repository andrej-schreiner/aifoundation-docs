The catalog separates modalities. Each one already has a guide. This page only points at them.

- **Image input** alongside text is [Vision](/guides/multimodal). The chat body uses a content array with `text` and `image_url`.
- **Audio** (speech to text) is [Audio](/guides/audio), on `POST /audio/transcriptions` and `POST /audio/translations`.
- **Image output** is [Image generation](/guides/image-generation), on `POST /images/generations`. No image model in the catalog runs on T-Cloud.
- **Scanned documents** are [OCR](/guides/ocr), preview models on T-Cloud.
