The Embedding API converts text into vector representations that capture semantic meaning. Use embeddings for semantic search, clustering, and RAG applications.

:::note[Prerequisites]
- An API key ([get one here](https://apikey.llmhub.t-systems.net/))
- OpenAI SDK or HTTP client installed ([Quickstart](/getting-started/quickstart))
:::

**What you'll learn:**
- How to generate embeddings from text
- Available embedding models and their use cases
- How to use embeddings for semantic search and RAG

  <TabItem value="python" label="Python">
    ```python showLineNumbers
    from openai import OpenAI

    client = OpenAI()

    texts = [
        "I am Batman and I'm rich",
        "I am Spiderman",
        "I am Ironman and I'm a billionaire",
        "I am Flash",
        "I am the president of USA",
    ]

    embeddings = client.embeddings.create(input=texts, model="jina-embeddings-v2-base-de")

    print("Embedding dimension:", len(embeddings.data[0].embedding))
    print("Number of vectors:", len(embeddings.data))
    print("Token usage:", embeddings.usage)
    ```

## RAG

Embed a passage, then send that passage to a chat model with the question. Both calls use the same client.

:::note[Prerequisites]
- An API key ([get one here](https://apikey.llmhub.t-systems.net/))
- The client from the [quickstart](/getting-started/quickstart)
- An embedding model and a chat model from [Recommended models](/getting-started/choosing-a-model)
:::

### Minimal example

`text-embedding-bge-m3` and `gpt-oss-120b` both run on T-Cloud. BGE-M3 has an 8K context window.

```python
import math

from openai import OpenAI

client = OpenAI()

passages = ["T-Cloud models in this catalog run in Germany."]
query = "Where do T-Cloud models run?"

embedded = client.embeddings.create(input=passages + [query], model="text-embedding-bge-m3")
passage_vecs = [item.embedding for item in embedded.data[:-1]]
query_vec = embedded.data[-1].embedding

def cos(a, b):
    return sum(x*y for x, y in zip(a, b)) / (math.sqrt(sum(x*x for x in a)) * math.sqrt(sum(y*y for y in b)))
best = max(range(len(passages)), key=lambda i: cos(query_vec, passage_vecs[i]))
context = passages[best]
print("vectors:", len(embedded.data))

response = client.chat.completions.create(
    model="gpt-oss-120b",
    messages=[
        {"role": "system", "content": "Answer only from the passage."},
        {"role": "user", "content": f"Passage:\n{context}\n\nQuestion: {query}"},
    ],
)
print(response.choices[0].message.content)
```

BGE-M3 returns 1024-dimensional vectors. Jina Embeddings v2 Base DE returns 768. The chat answer is in `choices[0].message.content`.

### Parameters

Embeddings take `model` and `input`. Chat takes `model` and `messages`.

### Limitations and troubleshooting

Qwen3 Embedding 8B also runs on T-Cloud, with a 32K context window.
