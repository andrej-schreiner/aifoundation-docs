## RAG

Embed a passage, then send that passage to a chat model with the question. Both calls use the same client.

:::note[Prerequisites]
- An API key ([get one here](https://apikey.llmhub.t-systems.net/))
- The client from the [quickstart](/)
- An embedding model and a chat model from [Choosing a model](/getting-started/choosing-a-model)
:::

## Minimal example

`text-embedding-bge-m3` and `gpt-oss-120b` both run on T-Cloud. BGE-M3 has an 8K context window.

```python
from openai import OpenAI

client = OpenAI()

passages = ["T-Cloud models in this catalog run in Germany."]
query = "Where do T-Cloud models run?"

embedded = client.embeddings.create(input=passages + [query], model="text-embedding-bge-m3")
passage_vecs = [item.embedding for item in embedded.data[:-1]]
query_vec = embedded.data[-1].embedding

def cos(a, b):
    return sum(x*y for x, y in zip(a, b)) / (math.sqrt(sum(x*x for x in a)) * math.sqrt(sum(y*y for y in b)))
best = max(range(len(passages)), key=lambda i: cos(query_vec, passage_vecs[i]))
context = passages[best]
print("vectors:", len(embedded.data))

response = client.chat.completions.create(
    model="gpt-oss-120b",
    messages=[
        {"role": "system", "content": "Answer only from the passage."},
        {"role": "user", "content": f"Passage:\n{context}\n\nQuestion: {query}"},
    ],
)
print(response.choices[0].message.content)
```

BGE-M3 returns 1024-dimensional vectors. Jina Embeddings v2 Base DE returns 768. The chat answer is in `choices[0].message.content`.

## Parameters

Embeddings take `model` and `input`. Chat takes `model` and `messages`.

## Visual RAG

Visual RAG indexes your files in both text and image, combining the stability of text indexing with the flexibility of visual indexing. It can retrieve information from graphs, charts, and complex table layouts that text-based RAG systems miss.

:::note[Prerequisites]
- An API key with Visual RAG access (contact **AlFoundation@t-systems.com**)
- OpenAI SDK installed ([Quickstart](/))
- Documents to index (PDF, PPTX, DOCX, HTML, or PNG)
:::

**What you'll learn:**
- How to upload files and create vector stores
- How to search with both text and image retrieval
- How to build an end-to-end RAG pipeline

**Supported formats:** PDF, PPTX, DOCX, HTML, PNG

## Vector Store Operations

### Create a Vector Store

```python
vs = client.vector_stores.create(
    name="my_vs",
    chunking_strategy={
        "text_embedding_model": "text-embedding-bge-m3",
        "vision_embedding_model": "tsi-embedding-colqwen2-2b-v1",
    },
)
print(f"Vector Store ID: {vs.id}")
```

### List Vector Stores

```python
for vs in client.vector_stores.list():
    print(f"{vs.name} ({vs.id}) - {vs.file_counts}")
```

### Ingest a File

```python
client.vector_stores.files.create(
    vector_store_id="xyz-456",
    file_id="file-abc123",
    chunking_strategy={
        "chunk_size": 1024,
        "chunk_overlap": 100,
    },
)
```

### List Ingested Files

```python
files = client.vector_stores.files.list(vector_store_id="xyz-456")

```

### Delete an Ingested File


### Delete a Vector Store

## Retrieval

Search your vector store with both text and image results:

```python
results = client.vector_stores.search(
    vector_store_id="xyz-456",
    query="Which new features are supported?",
    extra_body={
        "top_k_texts": 3,
        "top_k_images": 2,
    },
)

for result in results:
    if result.content[0].type == "text":
        print("Text result:", result.content[0].text[:200])
    elif result.content[0].type == "base64":
        print(f"Image result from {result.filename}, page {result.page_number}")
```


## End-to-End RAG Example

Combine retrieval with LLM inference for a complete Visual RAG pipeline:

```python

from openai import OpenAI

rag_client = OpenAI(
    api_key=os.getenv("OPENAI_API_KEY"),
    base_url="https://llm-server.llmhub.t-systems.net/v1",
)
llm_client = OpenAI(
    api_key=os.getenv("OPENAI_API_KEY"),
    base_url="https://llm-server.ai.t-systems.net/v1",
)

# 1. Retrieve relevant context
contexts = rag_client.vector_stores.search(
    vector_store_id="xyz-456",
    query="What are the key metrics?",
    extra_body={"top_k_texts": 5, "top_k_images": 3},
)

# 2. Build prompt with text and image contexts
content = [{"type": "text", "text": f"Based on the following context, answer: What are the key metrics?\n\n"}]
for ctx in contexts:
    if ctx.content[0].type == "text":
        content[0]["text"] += ctx.content[0].text + "\n\n"
    elif ctx.content[0].type == "base64":
        content.append({"type": "image_url", "image_url": {"url": ctx.content[0].text}})

# 3. Get answer from LLM
response = llm_client.chat.completions.create(
    model="Qwen-3.6-35B-FP8",
    messages=[{"role": "user", "content": content}],
    max_tokens=2048,
)

print(response.choices[0].message.content)
```
