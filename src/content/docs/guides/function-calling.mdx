Function calling lets models generate structured JSON arguments for functions you define, enabling integration with external tools and APIs.

:::note[Prerequisites]
- An API key ([get one here](https://apikey.llmhub.t-systems.net/))
- OpenAI SDK installed ([Quickstart](/getting-started/quickstart))
- A model that supports function calling (most hosted models do — see [Available Models](/models))
:::

**What you'll learn:**
- How to define tools/functions for the model to call
- How to use function calling with the Responses API
- Where the JSON Schema example moved ([Structured outputs](/guides/structured-outputs))


## Basic Example

<Tabs>
  <TabItem value="python" label="Python" default>
    ```python showLineNumbers
    from openai import OpenAI

    client = OpenAI()

    tools = [
        {
            "type": "function",
            "function": {
                "name": "get_current_weather",
                "description": "Get the current weather",
                "parameters": {
                    "type": "object",
                    "properties": {
                        "location": {
                            "type": "string",
                            "description": "The city and state, e.g. San Francisco, CA",
                        },
                        "format": {
                            "type": "string",
                            "enum": ["celsius", "fahrenheit"],
                            "description": "The temperature unit to use.",
                        },
                    },
                    "required": ["location", "format"],
                },
            },
        },
    ]

    messages = [
        {"role": "system", "content": "Don't make assumptions about what values to plug into functions. Ask for clarification if a user request is ambiguous."},
        {"role": "user", "content": "What's the weather like today in Hamburg?"},
    ]

    response = client.chat.completions.create(
        model="GLM-5.3",
        messages=messages,
        tools=tools,
    )

    print(response.choices[0].message)
    ```
  </TabItem>
</Tabs>

## Function Calling with Responses API

```python showLineNumbers
from openai import OpenAI

client = OpenAI()

tools = [
    {
        "type": "function",
        "name": "get_weather",
        "description": "Get current temperature for a given location.",
        "parameters": {
            "type": "object",
            "properties": {
                "location": {
                    "type": "string",
                    "description": "City and country e.g. Bogota, Colombia",
                }
            },
            "required": ["location"],
            "additionalProperties": False,
        },
    }
]

response = client.responses.create(
    model="GLM-5.3",
    input=[{"role": "user", "content": "What is the weather like in Paris today?"}],
    tools=tools,
)

print(response.output)
```

## Limitations and troubleshooting

:::note
Function calling works across a broad range of models on the platform, including OpenAI, Google and Anthropic models as well as many open-source ones. The model names used in this guide are examples only — they are not the only models that support the feature. Some T-Cloud-hosted open-source models do not support function calling yet; check the model's entry under [Available Models](/models) before relying on it.

The Responses API is not limited to OpenAI models either — tool calls through it are confirmed on Google, Anthropic and T-Cloud-hosted open-source models as well, though a few models still reject Responses API requests.
:::
