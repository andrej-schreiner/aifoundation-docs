For models that support reasoning (chain-of-thought), you can control the depth of reasoning with the `reasoning_effort` parameter.

:::note[Prerequisites]
- An API key ([get one here](https://apikey.llmhub.t-systems.net/))
- OpenAI SDK installed ([Quickstart](/getting-started/quickstart))
- A reasoning-capable model (see [Chat & Reasoning models](/models/llms))
:::

**What you'll learn:**
- How to tell whether a model supports reasoning control
- How to use the `reasoning_effort` parameter
- How to disable reasoning for Qwen 3.6 models

DeepSeek 4.1 Flash supports a thinking mode according to the vendor. Its `reasoning_effort` values on AIFS are not confirmed, so the table does not list them.

Qwen 3.6 also documents a prompt keyword, `/no_think`, in the section below. That keyword is not a column in the datasheet.

A few models are exceptions worth knowing about:

- **Mistral models** accept only `none` and `high`. Sending `low` or `medium` returns HTTP 400 with `reasoning_effort=... is not supported by Mistral models.`
- **Some newer Anthropic models** reject `reasoning_effort` and control thinking differently; the error names the alternative to use.
- **Code-specialised models** may reject the parameter outright with `The requested operation is unsupported.`

If a model rejects `reasoning_effort`, check its entry in [Chat & Reasoning models](/models/llms).


## Using reasoning_effort

<Tabs>
  <TabItem value="python" label="Python" default>
    ```python showLineNumbers
    from openai import OpenAI

    client = OpenAI()

    response = client.chat.completions.create(
        model="claude-sonnet-4.6",
        messages=[
            {"role": "system", "content": "You are a concise and helpful assistant."},
            {"role": "user", "content": "What is the capital of France?"},
        ],
        reasoning_effort="low",  # "low", "medium", or "high"
    )

    print(response.choices[0].message.content)
    ```
  </TabItem>
</Tabs>

The sample uses `reasoning_effort="low"` on `claude-sonnet-4.6`. That model retires on 2026-10-31. The datasheet table above is the list of values per model still in the catalog. Do not assume every model accepts only `low`, `medium`, and `high`.


## Disabling Reasoning for Qwen 3.6

For Qwen 3.6 models, prepend `/no_think` to your prompt to disable reasoning:

```python showLineNumbers
from openai import OpenAI

client = OpenAI()

response = client.chat.completions.create(
    model="Qwen3.6-35B-A3B-FP8",
    messages=[
        {"role": "system", "content": "You are a helpful assistant."},
        {"role": "user", "content": "/no_think What is your name?"},
    ],
)

print(response.choices[0].message.content)
```
