AI Foundation Services provides vision models that can analyze images alongside text. Use the same Chat Completions API with image content.

:::note[Prerequisites]
- An API key ([get one here](https://apikey.llmhub.t-systems.net/))
- OpenAI SDK or HTTP client installed ([Quickstart](/))
- A vision-capable model (see [Available Models](/models))
:::

**What you'll learn:**
- How to analyze images from URLs
- How to send local images via base64 encoding
- How to find out which models accept images

## Analyze a Local Image (Base64)

You can also pass a local image as a base64-encoded string:

```python showLineNumbers
import base64

from openai import OpenAI

client = OpenAI()

def encode_image(image_path):
    with open(image_path, "rb") as f:
        return base64.b64encode(f.read()).decode("utf-8")

base64_image = encode_image("/path/to/your/image.jpg")

response = client.chat.completions.create(
    model="Qwen-3.6-35B-FP8",
    messages=[
        {
            "role": "user",
            "content": [
                {"type": "text", "text": "What's in this image?"},
                {
                    "type": "image_url",
                    "image_url": {"url": f"data:image/jpeg;base64,{base64_image}"},
                },
            ],
        }
    ],
    max_tokens=1000,
)

print(response.choices[0].message.content)
```

## Limitations and troubleshooting

Scanned pages and handwriting belong on [OCR](/guides/ocr), which uses the preview models. This page is the chat image call.

:::caution[Per-request image limits differ by model]
T-Cloud-hosted models cap how many images one request may contain, and **the cap is not the same for every model**. `gemma-4-31B-it-FP8` accepts 10. `Qwen-3.6-35B-FP8` accepts 8.

Exceeding the cap returns HTTP 400, either `At most 10 image(s) may be provided in one prompt.` or `Image count 9 exceeds limit 8 per request.` Split large batches into multiple requests.
:::
