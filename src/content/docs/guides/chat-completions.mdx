The Chat Completions API is the primary way to interact with LLMs on AI Foundation Services. It's fully compatible with the OpenAI Chat API.

:::note[Prerequisites]
- An API key ([get one here](https://apikey.llmhub.t-systems.net/))
- OpenAI SDK or HTTP client installed ([Quickstart](/getting-started/quickstart))
:::

**What you'll learn:**
- How to send chat completion requests with system and user messages
- How to use streaming for real-time responses
- How to use the Completion and Responses APIs
- Key parameters for controlling output


## Basic Usage

<Tabs>
  <TabItem value="curl" label="curl" default>
    ```bash
    curl -X POST "$OPENAI_BASE_URL/chat/completions" \
      -H "Authorization: Bearer $OPENAI_API_KEY" \
      -H "Content-Type: application/json" \
      -d '{
        "model": "gpt-oss-120b",
        "messages": [
          {"role": "system", "content": "You are a helpful assistant."},
          {"role": "user", "content": "What is T-Cloud?"}
        ],
        "temperature": 0.1,
        "max_tokens": 256
      }'
    ```
  </TabItem>
  <TabItem value="python" label="Python">
    ```python showLineNumbers
    from openai import OpenAI

    client = OpenAI()

    response = client.chat.completions.create(
        model="gpt-oss-120b",
        messages=[
            {"role": "system", "content": "You are a helpful assistant."},
            {"role": "user", "content": "What is T-Cloud?"},
        ],
        temperature=0.1,
        max_tokens=256,
    )

    print(response.choices[0].message.content)
    ```
  </TabItem>
  <TabItem value="node" label="Node.js">
    ```javascript showLineNumbers

    const client = new OpenAI();

    const response = await client.chat.completions.create({
      model: "gpt-oss-120b",
      messages: [
        { role: "system", content: "You are a helpful assistant." },
        { role: "user", content: "What is T-Cloud?" },
      ],
      temperature: 0.1,
      max_tokens: 256,
    });

    console.log(response.choices[0].message.content);
    ```
  </TabItem>
</Tabs>


## Streaming

Enable streaming to receive tokens as they're generated. Set `stream: true` in your request:

```python
stream = client.chat.completions.create(
    model="gpt-oss-120b",
    messages=[{"role": "user", "content": "Write a short poem about AI."}],
    stream=True,
)

for chunk in stream:
    if chunk.choices and chunk.choices[0].delta.content:
        print(chunk.choices[0].delta.content, end="", flush=True)
```

For full streaming documentation including error handling, function calling with streams, and stream options, see the **[Streaming guide](/guides/streaming)**.


## Completion API

The Completion API sends raw text directly to the LLM without the chat message format.

<Tabs>
  <TabItem value="python" label="Python" default>
    ```python showLineNumbers
    from openai import OpenAI

    client = OpenAI()

    completion = client.completions.create(
        model="gpt-oss-120b",
        prompt="What is the Python programming language?",
        stream=False,
        temperature=0.2,
        max_tokens=128,
    )

    print(completion.choices[0].text)
    ```
  </TabItem>
</Tabs>

:::note
The Completions API is only available for open-source models. To get correct behavior, you need to follow the model's specific prompt template. **We recommend always using the [Chat Completions API](#basic-usage) instead.**
:::


## Response API

Using an up-to-date version of the OpenAI Python package, you can use the Responses API:

<Tabs>
  <TabItem value="python" label="Python" default>
    ```python showLineNumbers
    from openai import OpenAI

    client = OpenAI()

    response = client.responses.create(
        model="gpt-5",
        input="Write a one-sentence bedtime story about a unicorn.",
    )

    print(response.output_text)
    ```
  </TabItem>
</Tabs>

You can also use both input and instructions fields:

```python showLineNumbers
response = client.responses.create(
    model="gpt-5",
    instructions="You are a professional copywriter. Focus on benefits rather than features.",
    input="Create a product description for NoiseGuard Pro Headphones.",
    max_output_tokens=2000,
)

print(response.output_text)
```

:::note
The Responses API works with models from several providers — text, tool calls and streaming are all confirmed on OpenAI models (`gpt-5`), Google models (`gemini-3-flash`), Anthropic models (`claude-sonnet-4.6`) and T-Cloud-hosted open-source models (`gpt-oss-120b`). Coverage is still not universal: a few models reject Responses API requests and return HTTP 400. If you hit one, use the Chat Completions API, which is supported everywhere.
:::


## Parameters

| Parameter | Type | Description |
|---|---|---|
| `model` | string | Model ID (e.g., `gpt-oss-120b`) |
| `messages` | array | List of message objects with `role` and `content` |
| `temperature` | float | Sampling temperature (0-2). Lower = more deterministic |
| `max_tokens` | integer | Maximum tokens to generate |
| `stream` | boolean | Enable streaming responses |
| `top_p` | float | Nucleus sampling parameter |

For the full API specification, see the [API Reference](https://llm-server.llmhub.t-systems.net/redoc).


## Limitations and troubleshooting

Two limits are already on this page: the Completions API is only for open-source models and should not be your default, and some models reject the Responses API with HTTP 400.
