Point an application that already calls OpenAI or Azure OpenAI at AI Foundation Services. Keep the SDK. Change the base URL, the API key, and the model id.

The move from the current AIFS endpoint to the New API is a separate guide: [Migrate to the New API](/api-transition).

:::note[Prerequisites]
- An AIFS API key ([get one here](https://apikey.llmhub.t-systems.net/))
- The OpenAI SDK already installed
:::

## Minimal example

```bash
export OPENAI_API_KEY="your_api_key_here"
export OPENAI_BASE_URL="https://llm-server.llmhub.t-systems.net/v2"
```

```python
from openai import OpenAI

client = OpenAI()
response = client.chat.completions.create(
    model="gpt-oss-120b",
    messages=[{"role": "user", "content": "Hello from AIFS"}],
)
print(response.choices[0].message.content)
```

The response text is `response.choices[0].message.content`.

## Parameters

Set `OPENAI_BASE_URL` and `OPENAI_API_KEY`. The chat body uses `model` and `messages`.

Model ids on AIFS can differ from OpenAI model ids. [Choosing a model](/getting-started/choosing-a-model) lists the catalog. [Deprecations](/models/deprecations) lists retirement dates and replacements.

## Limitations and troubleshooting

The API is OpenAI-compatible. Not every parameter exists on every model. Some models return HTTP 400 for the Responses API. Use the guide for the call you are migrating.
