## Understanding model categories

- **Chat & reasoning** — General-purpose text generation, conversational agents, and reasoning.
- **Coding** — Code-tuned models for completion, refactoring, and review.
- **Embeddings** — Convert text to vectors for semantic search, clustering, and RAG.
- **Audio** — Speech-to-text models for transcription and translation.
- **Images** — Generate images from text prompts.

For data-handling details, see [Enterprise Trust](/reference/enterprise-trust).

## List models via API

<Tabs>
  <TabItem value="curl" label="curl" default>
    ```bash
    curl "$OPENAI_BASE_URL/models" \
      -H "Authorization: Bearer $OPENAI_API_KEY"
    ```
  </TabItem>
  <TabItem value="python" label="Python">
    ```python
    from openai import OpenAI

    client = OpenAI()

    models = client.models.list()
    for model in models.data:
        print(model.id)
    ```
  </TabItem>
  <TabItem value="node" label="Node.js">
    ```javascript
    import OpenAI from "openai";

    const client = new OpenAI();

    const models = await client.models.list();
    for (const model of models.data) {
      console.log(model.id);
    }
    ```
  </TabItem>
</Tabs>


## Model metadata

Each model includes metadata you can inspect:

```python
models = client.models.list()
print(models.data[0].meta_data)
```

```json
{
  "model_type": "LLM",
  "source_type": "OPEN SOURCE",
  "max_sequence_length": 128000,
  "hidden_size": 0,
  "max_output_length": 0,
  "deployment_region": "otc-germany",
  "location": "otc-germany",
  "license": "https://www.apache.org/licenses/LICENSE-2.0.html",
  "display_name": "GPT-OSS 120B",
  "deployment_country": "Germany, EU",
  "input_modalities": ["text"],
  "output_modalities": ["text"],
  "model_lifecycle_stage": "Stable",
  "is_externally_hosted": false
}
```

**Key fields:**
- **model_type** — `LLM`, `EMBEDDING`, `STT` (audio)
- **max_sequence_length** — Maximum input + output tokens
- **hidden_size** — Embedding vector dimensions (embedding models only)
- **max_output_length** — Maximum output tokens the model can generate
- **deployment_region** — Where the model is hosted (e.g., `otc-germany` for T-Cloud Germany)

## Hosting & compliance

- **Open-source models** are operated by <span class="nowrap">T-Systems</span> on the **T-Cloud** in Germany. Data is processed inside the EU/EEA, is not permanently stored, and is not viewable by Telekom or third parties.
- **Proprietary models** (GPT, Claude, Gemini) are forwarded to the upstream provider (Microsoft Azure or Google Cloud). The region depends on the model. Selecting one of these models accepts the third-party provider's terms.

**Customer data is not used for model training, regardless of which model you select.**

See [Enterprise Trust](/reference/enterprise-trust) for the full two-category data-handling breakdown.
