Major changes to AI Foundation Services — new models, feature updates, and deprecations.

## v1.2.3 — 2026-10

Aligns the documentation with the **[Service Description](/files/Leistungsbeschreibung_LLM_Serving-Service_EN.pdf)** as of 30 September 2026, which is the binding source for everything below.

### Added

- Responses that contain model output (chat and text completions, the Responses API, images, audio and decisions) now carry the HTTP response header `X-AI-Generated-Content: true`, which marks the content as AI generated in line with the EU AI Act. The response body is unchanged. See [API Endpoints](/reference/api-endpoints#response-format).
- Two new preview models in the Test catalog for **OCR**: **LightOnOCR-3-4B** (`LightOnOCR-3-4B-Preview`) from LightOn, Paris, and **PaddleOCR-VL-1.6** (`PaddleOCR-VL-1.6-Preview`). Free on any active plan. New guide: [OCR (Document Parsing)](/guides/ocr), with Chat Completions and library examples.
- New embedding model on the Essential, Professional and Agentic plans: **Qwen3 Embedding 8B** (`qwen3-embedding-8b`), multilingual, with a 32K context window. Same input-token and request limits as Jina Embeddings v2 Base DE; output tokens are not limited, since an embedding returns vectors. See [Plans & Pricing](/plans).
- New **[API Transition](/api-transition)** guide. The LLM Serving Service moves to the New API in three phases, with a Legacy endpoint for applications that need the current format; the guide covers the endpoints and what you need to do, API keys and model identifiers, and the changes to requests, responses, streaming and error handling.
- New preview model in the Test catalog: **d3**, a 27B decision model and the recommended model for the **Decisions** endpoint, with text and image input. Free on any active plan. See [Test / Preview Models](/plans/test) and the [Decisions guide](/guides/decisions).
- **Decisions** accepts image input on both preview models, d3 and DiffusionGemma 26B A4B. See [Image input](/guides/decisions#image-input).
- New preview model in the Test catalog: **DiffusionGemma 26B A4B**, free on any active plan, for chat and for the new **Decisions** endpoint. See [Test / Preview Models](/plans/test) and the [Decisions guide](/guides/decisions).
- New models on the Essential, Professional and Agentic plans: **GPT-6.1 Sol**, **GPT-6 Luna**, **Claude Sonnet 5.5**, and **Gemini 3.8 Flash**. **Claude Opus 5.5** on Professional and Agentic. See [Plans & Pricing](/plans).
- **GPT-6.1 Sol** and **GPT-6 Luna** are priced by context length, with separate rates above 272k input tokens.

### Changed

- **Gemini 3.1 Pro**, **Gemini 3.5 Flash** and **Gemini 3 Pro Image** now run on Dynamic Shared Quota instead of fixed RPM/TPM limits.
- The **Service Description** shipped with the docs has been updated.

### Deprecated

- **GPT-5** to **GPT 5.5**, **Claude 4.5 Haiku**, **Claude 4.6 Sonnet / Opus**, **Claude Opus 4.8** and **Gemini 3 Pro** retire on **2026-10-31**. **Gemini 3 Flash** retires on **2026-11-30**. See [Scheduled for Retirement](/models/scheduled-for-retirement) for replacements.

## v1.2.2 — 2026-09

Aligns the documentation with the **[Service Description](/files/Leistungsbeschreibung_LLM_Serving-Service_EN.pdf)** as of 31 August 2026, which is the binding source for everything below.

### Added

- **GLM 5.3 Flash** (`GLM-5.3-Flash`) and **Qwen 3.8 27B FP8** (`Qwen3.8-27B-FP8`) moved from preview to production on the Essential, Professional and Agentic plans. See [Plans & Pricing](/plans).
- New models on the Essential, Professional and Agentic plans: **GPT-5.6 Terra** and **GPT-5.6 Luna**. See [Plans & Pricing](/plans).
- **Gemini 3.1 Pro is now priced by context length.**
- **Cached input token pricing** on T-Cloud-hosted models. See [Prefix Caching](/guides/prefix-caching#pricing-for-cached-tokens).

### Changed

- **The Queue API is not asynchronous.** `/queue` endpoints work like `/v2`, but when you are over your rate limit they wait up to two minutes instead of returning `429` right away. The guide no longer mentions job polling or background processing. See [Queued Requests](/guides/queued-requests).
- **The availability target is 99.5%**, not the 99.9% previously published.
- **GLM 5.2** token prices reduced, and it moved to the **standard** model tier.
- **GPT-Image-2** pricing corrected.
- **Prefix caching is on by default** on T-Cloud-hosted models, not opt-in.
- Server location and data processing for the **Gemini 3 family** now read **Worldwide** instead of Europe. See [Enterprise Trust](/reference/enterprise-trust).
- The **Anthropic** models are labelled **GCP / Azure**.
- The **Service Description** shipped with the docs has been updated.
- **Enterprise Trust** category 1 now lists the models the Service Description names.

### Removed

- **Llama 3.3 70B**, **Claude 4.5 Sonnet** and **Claude 4.5 Opus** reached their retirement date. See [Retired Models](/models/retired) for replacements.

### Fixed

- **GLM 5.2** is listed on [Coding Models](/models/coding) again.
- **OpenCode**: corrected the authentication URL in the [plugin instructions](/plugins/opencode).
- `/category/model-serving` now redirects to the [guides](/guides) instead of returning a 404.

## v1.2.0 — 2026-07

### Added

- New models on the Essential, Professional and Agentic plans: **GPT-5.4**, **GPT-5.4 mini**, **GPT-5.5** and **GPT-Image-2** (OpenAI); **Gemini 3.1 Pro** and **Gemini 3.5 Flash** (Google). **Claude 4.8 Opus** (Anthropic) on Professional and Agentic. See [Plans & Pricing](/plans).
- **Mistral Small 4** and **Gemma 4** are now **generally available**, having been preview-only. See [Plans & Pricing](/plans).
- New preview model in the Test catalog: **GLM 5.2** — free on any active plan. See [Test / Preview Models](/plans/test).

### Deprecated

- Models across the **GPT-4.1**, **GPT-4o**, **o-series**, **Qwen3**, **Gemini 2.5**, **Gemini 3** and **Claude Sonnet / Opus** families are **scheduled for retirement on 2026-08-01**, along with **Mistral Small 3** and **GPT Image 1**. See [Scheduled for Retirement](/models/scheduled-for-retirement) for the table and replacements.
