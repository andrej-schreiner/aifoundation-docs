Major changes to AI Foundation Services — new models, feature updates, and deprecations.

## v1.2.0 — 2026-07

### Added

- New preview model in the Test catalog: `GLM 5.2` (`GLM-5.2-Preview`) from Zhipu AI — free to try on any active plan (Essential / Professional / Agentic). See [rate limits](/reference/rate-limits) for the preview-model policy.

## v1.1.0 — 2026-05

Archived snapshot: [v1.1.0](/v1-1-0/).

### Added

- New top-level **Models** section with a [comparison page](/models/comparison) covering every hosted model — context window, pricing, cloud, modalities, plan availability, and OpenAI-compatible endpoint reference. Image-capable models also surface on the dedicated [Vision page](/models/vision) via a capability filter.
- **Changelog** page (you are reading it).
- Two new preview models in the Test catalog: `Mistral Small 4` (`Mistral-Small-4-119B-2603-Preview`) and `Gemma 4` (`gemma-4-31B-it-FP8-preview`). See [rate limits](/reference/rate-limits) for the preview-model policy.

### Removed

- Fine-Tuning API documentation. The feature is no longer offered through AI Foundation Services. Requests to `/guides/fine-tuning` redirect here.
