OpenCode ist ein Open-Source-AI-Coding-Agent, der im Terminal läuft und neben jedem beliebigen Editor oder jeder IDE verwendet werden kann.

Mit OpenCode können Sie Fragen zu Ihrer Codebasis stellen, Code generieren oder umschreiben, Tests und Shell-Befehle ausführen und mehrstufige Änderungen über mehrere Dateien hinweg vom Agenten ausführen lassen — alles im Terminal, gegen AI Foundation Services-Modelle.

Es eignet sich besonders, wenn Sie einen tastaturzentrierten, editorunabhängigen Workflow bevorzugen und ein Werkzeug suchen, das Sie ohne IDE-Wechsel in jedes Projekt einbringen können.

## Hauptfunktionen

- LSP-Unterstützung, die das passende Sprach-Tooling für das Modell lädt
- Multi-Session-Workflows, sodass Sie mehrere Agenten im selben Projekt ausführen können
- Teilbare Session-Links für Zusammenarbeit und Debugging
- MCP-Unterstützung für externe Tools und Datenquellen
- Editor-unabhängiger Workflow, der in jeder IDE funktioniert

## Nutzungshinweise

:::caution[Bitte vor der Installation lesen]
- OpenCode ist eine angepasste Version des Plugins für den Unternehmenseinsatz ohne Telemetrie. Diese angepasste Version hat Telemetrie und Kommunikation zu Drittanbietern deaktiviert, und einige Funktionen wurden für eine unternehmenskonforme Nutzung verbessert.
- Bitte überprüfen Sie alle KI-generierten Inhalte sorgfältig, bevor Sie diese verwenden oder weitergeben. Gehen Sie dabei genauso vor wie bei Ihrer manuellen Arbeit (z. B. Peer-Reviews, Vier-Augen-Prinzip usw.). Die KI-Komponenten von AIFS können Fehler machen.
- Geben Sie keine personenbezogenen Daten ein.
- Wenn Sie weitere Fragen zu den KI-Komponenten von AIFS haben, lesen Sie bitte die entsprechende Dokumentation. Für zusätzliche Fragen oder Anregungen wenden Sie sich bitte an das AI Engineer Support Team.
- Verwenden Sie den Assistenten ausschließlich für Ihre beruflichen Anfragen.
- Die eingegebenen Daten werden nicht zum Training der großen Sprachmodelle verwendet.
- Der Assistent arbeitet in der Regel schnell, bei komplexen Anfragen oder Dokumentensuchen kann es jedoch etwas länger dauern. Bitte haben Sie Geduld und warten Sie auf die vollständige Antwort des Assistenten.
- KI-Modelle wie ChatGPT sind generative Modelle, d. h. sie erzeugen Texte ohne explizit überprüfbare Fakten. Dies kann dazu führen, dass der Assistent plausible, aber nicht unbedingt korrekte Informationen liefert.
- Der Einsatz von AI Engineer in Hochrisikobereichen [Anhang III AIA](https://ai-act-service-desk.ec.europa.eu/en/ai-act/annex-3) oder für Kunden in regulierten Sektoren [Anhang I AIA](https://ai-act-service-desk.ec.europa.eu/en/ai-act/annex-1) ist nicht gestattet.
:::

## Installation und Einrichtung

:::note[Proxy-Nutzung]
Wie die meisten Kommandozeilen-Tools benötigt OpenCode unter Umständen Proxy-Einstellungen in Ihrer Shell-Umgebung. Wenn Sie unter Windows arbeiten und einen Proxy benötigen, setzen Sie diese Variablen, bevor Sie OpenCode starten:

```bash
http_proxy=<your-proxy-url:port>
https_proxy=<your-proxy-url:port>
```
:::

1. Befolgen Sie die OpenCode-Installationsanweisungen auf [AI Coding Plugins](https://apikey.llmhub.t-systems.net/plugins).

2. Authentifizieren Sie sich mit der gesicherten Konfiguration:

   ```bash
   opencode auth login https://plugins.ai.t-systems.net/
   ```

3. Starten Sie OpenCode:

   ```bash
   opencode
   ```

4. Führen Sie in OpenCode den folgenden Befehl aus, um Ihren Provider auszuwählen und sich mit Ihrem API-Key anzumelden:

   ```bash
   /connect
   ```

   Wählen Sie **AI Foundation Services** aus der Provider-Liste und geben Sie auf Aufforderung Ihren API-Key ein. Sie können einen API-Key in [LLM Serving API Keys](https://apikey.llmhub.t-systems.net/dashboard) erzeugen.

Sie können nun einen Chat starten und OpenCode verwenden.

## Erste Schritte mit OpenCode

Sobald OpenCode läuft, arbeiten Sie in natürlicher Sprache mit dem Agenten. Einige Prompts zum Ausprobieren in Ihrem Projektverzeichnis:

- `Fasse zusammen, was dieses Repository tut und wie die Hauptmodule zusammenspielen.`
- `Refaktoriere getUserById in src/db/users.ts so, dass async/await statt Promise-Ketten verwendet wird.`
- `Führe die Tests aus und behebe etwaige Fehler.`

Eine vollständige Liste der In-Session-Kommandos und weiterführende Konfiguration (eigene Agenten, MCP-Server, Regeln) finden Sie in der [OpenCode-Originaldokumentation](https://opencode.ai/docs).

## Beispiel-Konfiguration

Wenn Sie OpenCode lieber deklarativ konfigurieren oder ein Standardmodell und eine Base URL fest hinterlegen möchten, legen Sie `opencode.json` im Projekt-Stamm oder unter `~/.config/opencode/opencode.json` als globalen Standard an:

```jsonc
{
  "$schema": "https://opencode.ai/config.json",
  "model": "openai/gpt-4.1", // Standardmodell setzen (Format: provider_id/model_id)

  "provider": {
    "openai": {
      "options": {
        "baseURL": "https://llm-server.llmhub.t-systems.net/v2"
      }
    }
  },

  // Berechtigungen für integrierte Tools setzen
  "permission": {
    "edit": "allow",
    "websearch": "allow"
  }
}
```

OpenCode liest `OPENAI_API_KEY` automatisch aus der Umgebung, sodass die Konfiguration nur die `baseURL` benötigt. Wenn Sie die Variable im [Quickstart](/de/getting-started/quickstart) gesetzt haben, ist hier keine weitere Key-Konfiguration nötig.
