Modelle, deren Stilllegung aus AI Foundation Services geplant ist. Kunden sollten die Migration zum empfohlenen Ersatzmodell vor dem Stilllegungsdatum einplanen.

| Anbieter | Modell | Stilllegungsdatum | Empfohlener Ersatz |
|---|---|---|---|
| OpenAI | GPT-5 nano / GPT-5 mini / GPT 5.4 mini | 31.10.2026 | GPT-6 Luna |
| OpenAI | GPT-5 / GPT-5 Codex / GPT 5.4 / GPT 5.5 | 31.10.2026 | GPT-6.1 Sol |
| Anthropic | Claude 4.5 Haiku / Claude 4.6 Sonnet | 31.10.2026 | Claude Sonnet 5.5 |
| Anthropic | Claude 4.6 Opus / Claude Opus 4.8 | 31.10.2026 | Claude Opus 5.5 |
| Google | Gemini 3 Pro (≤200k) | 31.10.2026 | Gemini 3.1 Pro (≤200k) |
| Google | Gemini 3 Pro (>200k) | 31.10.2026 | Gemini 3.1 Pro (>200k) |
| Google | Gemini 3 Flash | 30.11.2026 | Gemini 3.8 Flash |

Nach dem Stilllegungsdatum geben Anfragen an diese Modell-IDs einen Fehler zurück, der das Ersatzmodell nennt.

:::caution[Wichtig]
Wenn Sie eines der oben genannten Modelle nutzen, migrieren Sie vor dem **31.10.2026** (Gemini 3 Flash: **30.11.2026**) zum Ersatzmodell.
:::

Größere Änderungen werden auch im [Änderungsprotokoll](/de/changelog) angekündigt.
