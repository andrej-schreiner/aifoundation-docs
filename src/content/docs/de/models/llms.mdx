Allgemeine Textgenerierung, Konversationsagenten und Reasoning. Die meisten LLMs auf AI Foundation Services akzeptieren mehrsprachige Eingaben und unterstützen Streaming sowie Tool-/Function-Calling. GPT-6-Modelle rufen Tools über die Responses API auf; siehe [Function Calling](/de/guides/function-calling#grenzen-und-fehlersuche).

Die Katalogeinträge verwenden Katalog-IDs, etwa `Qwen-3.6-35B-FP8` und `Nemotron-3-Super-120B-FP8`. Welche Modelle verfügbar sind, kann vom Host und vom API-Schlüssel abhängen. Prüfen Sie die aktuellen IDs daher mit `GET /v2/models` (siehe [Modelle über die API auflisten](/de/models#modelle-über-die-api-auflisten)).
