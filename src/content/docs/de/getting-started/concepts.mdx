## Tokens

Ein Token ist die Einheit, die die API zählt. Chat-Anfragen setzen `max_tokens` für die Anzahl der zu erzeugenden Tokens. Rate-Limits zählen Tokens pro Minute.

## TPM

Tokens pro Minute. Ein Shared-Tarif gibt ein Input-TPM und ein Output-TPM je Modell an. Die Werte stehen unter [Rate-Limits](/de/reference/rate-limits).

## RPM

Anfragen pro Minute. Ein Shared-Tarif gibt an, wie viele Anfragen Sie je Modell senden können. Dieselbe Seite wie beim TPM: [Rate-Limits](/de/reference/rate-limits).

## Kontextfenster

Wie viel Text ein Modell in einer Anfrage akzeptiert, wie im Katalog angegeben (`8K`, `128K`, `1M`). Siehe [Modell wählen](/de/getting-started/choosing-a-model).

## T-Cloud

Von der Telekom gehostete Modelle. Im Katalog ist ihre Region Deutschland. [Enterprise Trust](/de/reference/enterprise-trust) beschreibt, wie Prompts für diese Modelle verarbeitet werden. Die Bezeichnung im Produkt ist T-Cloud.

## Partnermodelle

Modelle, die die API an einen anderen Anbieter weiterleitet. Die Katalogregionen sind Microsoft Azure oder Google Cloud: eine genannte Region wie Schweden, Frankreich oder `europe-west1`, oder weltweit. Die Datenverarbeitung für diesen Weg steht unter [Enterprise Trust](/de/reference/enterprise-trust).

## OpenAI-kompatibel

Die HTTP-API nimmt das OpenAI SDK an. Der [Quickstart](/de/) setzt `OPENAI_BASE_URL` und sendet `chat/completions`. Prüfen Sie die Anleitung für den Aufruf, den Sie ausführen. Nicht jeder OpenAI-Parameter existiert auf jedem Modell.

## Reasoning effort

`reasoning_effort` bei Modellen, deren Datenblatt zulässige Werte angibt. Die Liste gilt je Modell. Siehe [Reasoning](/de/guides/reasoning).

## Embeddings

Ein Vektor für einen Text, über `POST /embeddings`. Für semantische Suche und Retrieval. Siehe [Embeddings](/de/guides/embeddings).
