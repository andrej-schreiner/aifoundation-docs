AI Foundation Services bietet eine OpenAI-kompatible REST-API. Alle Endpunkte verwenden die Basis-URL:

```
https://llm-server.ai.t-systems.net/v1
```

Die vollständige OpenAPI-Spezifikation finden Sie in der [interaktiven API-Dokumentation (Redoc)](https://llm-server.llmhub.t-systems.net/redoc).


## Endpunkte

| Methode | Endpunkt | Beschreibung |
|---|---|---|
| `GET` | `/models` | Alle verfügbaren Modelle auflisten |
| `GET` | `/models/{model_id}` | Modelldetails und Metadaten abrufen |
| `POST` | `/chat/completions` | Eine Chat Completion erstellen |
| `POST` | `/completions` | Eine Text Completion erstellen |
| `POST` | `/embeddings` | Embeddings erstellen |
| `POST` | `/audio/transcriptions` | Audio in Text transkribieren |
| `POST` | `/audio/translations` | Audio ins Englische übersetzen |
| `GET` | `/audio/models` | Verfügbare Audio-Modelle auflisten |
| `POST` | `/images/generations` | Bilder aus Text generieren |
| `POST` | `/images/edits` | Ein Bild bearbeiten. Der Abschnitt [Queued Requests](/de/guides/reliability#queued-requests) dokumentiert diesen Pfad. |
| `POST` | `/responses` | Eine Antwort erstellen (Responses API) |
| `POST` | `/decisions` | Typisierte Entscheidung. Siehe [Decisions](/de/guides/decisions). |
| `POST` | `/files` | Eine Datei hochladen |
| `GET` | `/files` | Hochgeladene Dateien auflisten |
| `DELETE` | `/files/{id}` | Eine Datei löschen |

Die Pfade oben sind relativ zu `https://llm-server.ai.t-systems.net/v1`, der Chat-Pfad ist also `/v1/chat/completions`.

### Queue-Endpunkte

Die Migrationsseiten nennen kein Gegenstück auf dem neuen Endpunkt für den Queue-Host. Diese Pfade bleiben auf `https://llm-server.llmhub.t-systems.net`. Sie warten bis zu zwei Minuten, wenn das Rate-Limit überschritten ist, statt sofort `429` zu liefern. Siehe [Queued Requests](/de/guides/reliability#queued-requests).

| Methode | Endpunkt | Beschreibung |
|---|---|---|
| `POST` | `/queue/chat/completions` | Chat Completion (Queue) |
| `POST` | `/queue/completions` | Text Completion (Queue) |
| `POST` | `/queue/embeddings` | Embeddings (Queue) |
| `POST` | `/queue/audio/transcriptions` | Audio Transcription (Queue) |
| `POST` | `/queue/audio/translations` | Audio Translation (Queue) |
| `POST` | `/queue/images/generations` | Image Generation (Queue) |
| `POST` | `/queue/images/edits` | Image Edit (Queue) |
| `GET` | `/queue/models` | Modelle auflisten (Queue) |


## Hosts

Die Basis der neuen API ist `https://llm-server.ai.t-systems.net/v1`. Standardaufrufe nutzen `/v1/...` auf diesem Host. Für einige Pfade in dieser Doku gibt es noch kein Gegenstück auf dem neuen Endpunkt, sie bleiben auf dem bisherigen Host:

| Host | Wofür die Doku ihn verwendet |
|---|---|
| `https://llm-server.ai.t-systems.net/v1` | Chat, Completions, Responses, Embeddings, Audio, Bilder, Decisions, Dateien, Modelle |
| `https://llm-server.llmhub.t-systems.net/v2/coding` | Cline, Continue und OpenCode. Die Migrationsseiten definieren keinen Coding-Pfad unter `/v1`. |
| `https://llm-server.llmhub.t-systems.net/queue` | Queue-Varianten wie `/queue/chat/completions` und `/queue/images/edits` |
| `https://llm-server.llmhub.t-systems.net/v1` | Visual-RAG-Vektorspeicher (`/v1/vector_stores`) auf dem bisherigen Host |

Die Seite [Umstieg auf die neue API](/de/api-transition) beschreibt den Wechsel vom bisherigen Endpunkt zu `https://llm-server.ai.t-systems.net/v1`.


## Authentifizierung

Alle Anfragen erfordern einen API-Schlüssel im `Authorization`-Header:

```
Authorization: Bearer YOUR_API_KEY
```

Weitere Details zur Einrichtung finden Sie unter [Authentifizierung](/de/getting-started/authentication).


## Anfrageformat

Alle POST-Anfragen verwenden JSON:

```bash
curl -X POST "https://llm-server.ai.t-systems.net/v1/chat/completions" \
  -H "Authorization: Bearer $OPENAI_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"model": "gpt-oss-120b", "messages": [{"role": "user", "content": "Hello"}]}'
```


## Antwortformat

Antworten folgen dem OpenAI-Antwortformat. Für Chat Completions:

```json
{
  "id": "chatcmpl-abc123",
  "object": "chat.completion",
  "created": 1710000000,
  "model": "gpt-oss-120b",
  "choices": [
    {
      "index": 0,
      "message": {
        "role": "assistant",
        "content": "Hello! How can I help you today?"
      },
      "finish_reason": "stop"
    }
  ],
  "usage": {
    "prompt_tokens": 10,
    "completion_tokens": 9,
    "total_tokens": 19
  }
}
```

:::note[KI-generierte Inhalte]
Antworten mit Modellausgaben (Chat und Text Completions, Responses API, Bilder, Audio und Decisions) enthalten den HTTP-Antwort-Header `X-AI-Generated-Content: true`, der den Inhalt gemäß EU AI Act als KI-generiert kennzeichnet. Der Antwort-Body bleibt unverändert. Embeddings, Modelllisten, Dateioperationen und Fehlerantworten enthalten den Header nicht.
:::
