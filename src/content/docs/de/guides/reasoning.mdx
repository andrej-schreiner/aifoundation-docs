Für Modelle, die Reasoning (Chain-of-Thought) unterstützen, können Sie die Tiefe des Reasoning-Prozesses mit dem Parameter `reasoning_effort` steuern.

:::note[Voraussetzungen]
- Ein API-Schlüssel ([hier erhalten](https://apikey.llmhub.t-systems.net/))
- OpenAI SDK installiert ([Quickstart](/de/getting-started/quickstart))
- Ein Reasoning-fähiges Modell (siehe [Chat & Reasoning (LLMs)](/de/models/llms))
:::

**Was Sie lernen werden:**
- Wie Sie erkennen, ob ein Modell Reasoning-Steuerung unterstützt
- Wie Sie den Parameter `reasoning_effort` verwenden
- Wie Sie Reasoning für Qwen 3.6-Modelle deaktivieren


## Beispiele für Reasoning-Steuerung

:::note[Beispiele, keine vollständige Liste]
Die folgende Tabelle zeigt einige gängige Modelle und wie Reasoning dort gesteuert wird. Sie ist **keine** vollständige Aufzählung — weitere Modelle auf der Plattform unterstützen Reasoning-Steuerung ebenfalls, und der Katalog ändert sich laufend. Die aktuelle Liste finden Sie unter [Chat & Reasoning (LLMs)](/de/models/llms) oder über den [Models-Endpunkt](/de/reference/api-endpoints).
:::

| Modell (Beispiel) | Reasoning |
|---|---|
| GPT-5, GPT-5 mini, GPT-5 nano | Parameter `reasoning_effort` |
| Gemini 3 | Parameter `reasoning_effort` |
| Claude 4.6, Claude Opus 5 | Parameter `reasoning_effort` |
| Qwen 3.6 | Prompt-Schlüsselwort `/no_think` |

Die meisten Reasoning-Modelle folgen einem dieser beiden Muster: dem OpenAI-kompatiblen Parameter `reasoning_effort` oder einem Prompt-Schlüsselwort. Lehnt ein Modell `reasoning_effort` ab, prüfen Sie seinen Eintrag unter [Chat & Reasoning (LLMs)](/de/models/llms).


## Verwendung von reasoning_effort

<Tabs>
  <TabItem value="python" label="Python" default>
    ```python showLineNumbers
    from openai import OpenAI

    client = OpenAI()

    response = client.chat.completions.create(
        model="claude-sonnet-4.6",
        messages=[
            {"role": "system", "content": "You are a concise and helpful assistant."},
            {"role": "user", "content": "What is the capital of France?"},
        ],
        reasoning_effort="low",  # "low", "medium", or "high"
    )

    print(response.choices[0].message.content)
    ```
  </TabItem>
</Tabs>

Der Parameter `reasoning_effort` akzeptiert drei Werte:
- **`low`** — Schnelle Antworten, minimales Reasoning
- **`medium`** — Ausgewogene Reasoning-Tiefe
- **`high`** — Tiefgehendes Reasoning für komplexe Probleme


## Reasoning für Qwen 3.6 deaktivieren

Für Qwen 3.6-Modelle stellen Sie `/no_think` Ihrem Prompt voran, um Reasoning zu deaktivieren:

```python showLineNumbers
from openai import OpenAI

client = OpenAI()

response = client.chat.completions.create(
    model="Qwen-3.6-35B-FP8",
    messages=[
        {"role": "system", "content": "You are a helpful assistant."},
        {"role": "user", "content": "/no_think What is your name?"},
    ],
)

print(response.choices[0].message.content)
```
