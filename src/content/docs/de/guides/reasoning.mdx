Für Modelle, die Reasoning (Chain-of-Thought) unterstützen, können Sie die Tiefe des Reasoning-Prozesses mit dem Parameter `reasoning_effort` steuern.

:::note[Voraussetzungen]
- Ein API-Schlüssel ([hier erhalten](https://apikey.llmhub.t-systems.net/))
- OpenAI SDK installiert ([Quickstart](/de/getting-started/quickstart))
- Ein Reasoning-fähiges Modell (siehe [Chat & Reasoning (LLMs)](/de/models/llms))
:::

**Was Sie lernen werden:**
- Wie Sie erkennen, ob ein Modell Reasoning-Steuerung unterstützt
- Wie Sie den Parameter `reasoning_effort` verwenden
- Wie Sie Reasoning für Qwen 3.6-Modelle deaktivieren


## Zulässige Werte

Die Tabelle ist das Plattform-Datenblatt (Werte von `reasoning_effort` und der Default aus dem Datenblatt). Modelle mit Stilllegung am 31.10.2026 oder 30.11.2026 fehlen. Ein Modell mit leerer Werteliste im Datenblatt fehlt ebenfalls.

<ReasoningTable />

Für Qwen 3.6 dokumentiert der Abschnitt unten zusätzlich das Prompt-Schlüsselwort `/no_think`. Dieses Schlüsselwort ist keine Spalte im Datenblatt.

Einige Modelle bilden Ausnahmen:

- **Mistral-Modelle** akzeptieren nur `none` und `high`. `low` oder `medium` führen zu HTTP 400 mit `reasoning_effort=... is not supported by Mistral models.`
- **Einzelne neuere Anthropic-Modelle** lehnen `reasoning_effort` ab und steuern Thinking anders; die Fehlermeldung nennt die zu verwendende Alternative.
- **Auf Code spezialisierte Modelle** weisen den Parameter mit `The requested operation is unsupported.` zurück.

Lehnt ein Modell `reasoning_effort` ab, prüfen Sie seinen Eintrag unter [Chat & Reasoning (LLMs)](/de/models/llms).


## Verwendung von reasoning_effort

<Tabs>
  <TabItem value="python" label="Python" default>
    ```python showLineNumbers
    from openai import OpenAI

    client = OpenAI()

    response = client.chat.completions.create(
        model="claude-sonnet-4.6",
        messages=[
            {"role": "system", "content": "You are a concise and helpful assistant."},
            {"role": "user", "content": "What is the capital of France?"},
        ],
        reasoning_effort="low",  # "low", "medium", or "high"
    )

    print(response.choices[0].message.content)
    ```
  </TabItem>
</Tabs>

Das Beispiel setzt `reasoning_effort="low"` auf `claude-sonnet-4.6`. Dieses Modell wird am 31.10.2026 stillgelegt. Die Datenblatt-Tabelle oben ist die Werteliste je Modell, das noch im Katalog steht. Nicht davon ausgehen, dass jedes Modell nur `low`, `medium` und `high` akzeptiert.


## Reasoning für Qwen 3.6 deaktivieren

Für Qwen 3.6-Modelle stellen Sie `/no_think` Ihrem Prompt voran, um Reasoning zu deaktivieren:

```python showLineNumbers
from openai import OpenAI

client = OpenAI()

response = client.chat.completions.create(
    model="Qwen3.6-35B-A3B-FP8",
    messages=[
        {"role": "system", "content": "You are a helpful assistant."},
        {"role": "user", "content": "/no_think What is your name?"},
    ],
)

print(response.choices[0].message.content)
```


## Grenzen und Fehlersuche

Diese Grenzen stehen bereits auf dieser Seite:

- Mistral-Modelle akzeptieren nur `none` und `high`. `low` oder `medium` führen zu HTTP 400 mit `reasoning_effort=... is not supported by Mistral models.`
- Einzelne neuere Anthropic-Modelle lehnen `reasoning_effort` ab. Die Fehlermeldung nennt die Alternative.
- Einige auf Code spezialisierte Modelle weisen den Parameter mit `The requested operation is unsupported.` zurück.
