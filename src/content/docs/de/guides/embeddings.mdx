## RAG

Vektorisieren Sie eine Textstelle und senden Sie sie zusammen mit der Frage an ein Chat-Modell. Beide Aufrufe nutzen denselben Client.

:::note[Voraussetzungen]
- Ein API-Schlüssel ([hier erhalten](https://apikey.llmhub.t-systems.net/))
- Der Client aus dem [Quickstart](/de/)
- Ein Embedding-Modell und ein Chat-Modell aus [Modell wählen](/de/getting-started/choosing-a-model)
:::

## Minimales Beispiel

`text-embedding-bge-m3` und `gpt-oss-120b` laufen beide auf T-Cloud. BGE-M3 hat ein Kontextfenster von 8K.

```python
from openai import OpenAI

client = OpenAI()

passages = ["T-Cloud models in this catalog run in Germany."]
query = "Where do T-Cloud models run?"

embedded = client.embeddings.create(input=passages + [query], model="text-embedding-bge-m3")
passage_vecs = [item.embedding for item in embedded.data[:-1]]
query_vec = embedded.data[-1].embedding

def cos(a, b):
    return sum(x*y for x, y in zip(a, b)) / (math.sqrt(sum(x*x for x in a)) * math.sqrt(sum(y*y for y in b)))
best = max(range(len(passages)), key=lambda i: cos(query_vec, passage_vecs[i]))
context = passages[best]
print("vectors:", len(embedded.data))

response = client.chat.completions.create(
    model="gpt-oss-120b",
    messages=[
        {"role": "system", "content": "Answer only from the passage."},
        {"role": "user", "content": f"Passage:\n{context}\n\nQuestion: {query}"},
    ],
)
print(response.choices[0].message.content)
```

BGE-M3 liefert 1024-dimensionale Vektoren. Jina Embeddings v2 Base DE liefert 768. Die Chat-Antwort steht in `choices[0].message.content`.

## Parameter

Embeddings nehmen `model` und `input`. Chat nimmt `model` und `messages`.

## Grenzen und Fehlersuche

Qwen3 Embedding 8B läuft ebenfalls auf T-Cloud, mit einem Kontextfenster von 32K.

## Visual RAG

Visual RAG indiziert Ihre Dateien sowohl als Text als auch als Bild und kombiniert die Stabilität der Textindizierung mit der Flexibilität der visuellen Indizierung. Es kann Informationen aus Grafiken, Diagrammen und komplexen Tabellenlayouts abrufen, die textbasierte RAG-Systeme übersehen.

:::note[Voraussetzungen]
- Ein API-Schlüssel mit Visual RAG-Zugang (kontaktieren Sie **AlFoundation@t-systems.com**)
- OpenAI SDK installiert ([Quickstart](/de/))
- Zu indizierende Dokumente (PDF, PPTX, DOCX, HTML oder PNG)
:::

**Was Sie lernen werden:**
- Wie Sie Dateien hochladen und Vektorspeicher erstellen
- Wie Sie mit Text- und Bildabruf suchen
- Wie Sie eine End-to-End-RAG-Pipeline aufbauen

**Unterstützte Formate:** PDF, PPTX, DOCX, HTML, PNG

uploaded = client.files.create(

file_list = client.files.list(purpose="visual-rag")

```python
client.files.delete("file-abc123")
```


## Vektorspeicher-Operationen

### Vektorspeicher erstellen

```python
vs = client.vector_stores.create(
    name="my_vs",
    chunking_strategy={
        "text_embedding_model": "text-embedding-bge-m3",
        "vision_embedding_model": "tsi-embedding-colqwen2-2b-v1",
    },
)
print(f"Vector Store ID: {vs.id}")
```

### Vektorspeicher auflisten

```python
for vs in client.vector_stores.list():
    print(f"{vs.name} ({vs.id}) - {vs.file_counts}")
```

### Datei aufnehmen

```python
client.vector_stores.files.create(
    vector_store_id="xyz-456",
    file_id="file-abc123",
    chunking_strategy={
        "chunk_size": 1024,
        "chunk_overlap": 100,
    },
)
```

### Aufgenommene Dateien auflisten

```python
files = client.vector_stores.files.list(vector_store_id="xyz-456")
for f in files.data:
    print(f"{f.id} - {f.created_at}")
```

### Aufgenommene Datei löschen

```python
client.vector_stores.files.delete(
    vector_store_id="xyz-456",
    file_id="file-abc123",
)
```

### Vektorspeicher löschen

```python

```


## Abruf

Durchsuchen Sie Ihren Vektorspeicher mit Text- und Bildergebnissen:

```python
results = client.vector_stores.search(
    vector_store_id="xyz-456",
    query="Which new features are supported?",
    extra_body={
        "top_k_texts": 3,
        "top_k_images": 2,
    },
)

for result in results:
    if result.content[0].type == "text":
        print("Text result:", result.content[0].text[:200])
    elif result.content[0].type == "base64":
        print(f"Image result from {result.filename}, page {result.page_number}")
```


## End-to-End RAG-Beispiel

Kombinieren Sie den Abruf mit LLM-Inferenz für eine vollständige Visual RAG-Pipeline:

```python

from openai import OpenAI

rag_client = OpenAI(
    api_key=os.getenv("OPENAI_API_KEY"),
    base_url="https://llm-server.llmhub.t-systems.net/v1",
)
llm_client = OpenAI(
    api_key=os.getenv("OPENAI_API_KEY"),
    base_url="https://llm-server.ai.t-systems.net/v1",
)

# 1. Retrieve relevant context
contexts = rag_client.vector_stores.search(
    vector_store_id="xyz-456",
    query="What are the key metrics?",
    extra_body={"top_k_texts": 5, "top_k_images": 3},
)

# 2. Build prompt with text and image contexts
content = [{"type": "text", "text": f"Based on the following context, answer: What are the key metrics?\n\n"}]
for ctx in contexts:
    if ctx.content[0].type == "text":
        content[0]["text"] += ctx.content[0].text + "\n\n"
    elif ctx.content[0].type == "base64":
        content.append({"type": "image_url", "image_url": {"url": ctx.content[0].text}})

# 3. Get answer from LLM
response = llm_client.chat.completions.create(
    model="Qwen-3.6-35B-FP8",
    messages=[{"role": "user", "content": content}],
    max_tokens=2048,
)

print(response.choices[0].message.content)
```
