Retrieval-Augmented Generation bedeutet hier zwei Aufrufe, die es schon gibt: Embeddings, dann eine Chat Completion, die den gefundenen Text enthält. Diese Seite fügt keine Vektordatenbank hinzu.

:::note[Voraussetzungen]
- Ein API-Schlüssel ([hier erhalten](https://apikey.llmhub.t-systems.net/))
- Der Client aus dem [Quickstart](/de/)
- Ein Embedding-Modell und ein Chat-Modell aus [Modell wählen](/de/getting-started/choosing-a-model)
:::

## Minimales Beispiel

Der Embedding-Aufruf ist der aus der [Embeddings-Anleitung](/de/guides/embeddings), mit `text-embedding-bge-m3` (T-Cloud, Kontext 8K). Der Chat-Aufruf nutzt `gpt-oss-120b`, das Quickstart-Modell, ebenfalls auf T-Cloud. Die „gefundene“ Zeichenkette ist Text, den Sie schon haben. Nichts in den Dokumenten speichert ihn für Sie.

```python
from openai import OpenAI

client = OpenAI()

passage = "T-Cloud models in this catalog run in Germany."
query = "Where do T-Cloud models run?"

embedded = client.embeddings.create(input=[passage, query], model="text-embedding-bge-m3")
print("vectors:", len(embedded.data))

response = client.chat.completions.create(
    model="gpt-oss-120b",
    messages=[
        {"role": "system", "content": "Answer only from the passage."},
        {"role": "user", "content": f"Passage:\n{passage}\n\nQuestion: {query}"},
    ],
)
print(response.choices[0].message.content)
```

Die Embeddings-Anleitung zeichnet diese Ergebnisform für das Jina-Modell auf: eine Embedding-Dimension, eine Vektoranzahl und die Token-Nutzung. Für BGE-M3 liegt kein Beispiel vor, deshalb erfindet diese Seite keines. Der Chat-Aufruf liefert Nachrichteninhalt wie der Quickstart.

## Parameter

Embeddings: `model` und `input`, wie in der Embeddings-Anleitung. Chat: `model` und `messages`, wie in der Chat-Completions-Anleitung.

## Grenzen und Fehlersuche

Die Embeddings-Anleitung listet zwei Beispielmodelle und ihre Dimensionen: `jina-embeddings-v2-base-de` (768) und `text-embedding-bge-m3` (1024). Qwen3 Embedding 8B läuft ebenfalls auf T-Cloud; seine Dimension steht auf dieser Seite nicht.
