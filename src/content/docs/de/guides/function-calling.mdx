Function Calling ermöglicht es Modellen, strukturierte JSON-Argumente für von Ihnen definierte Funktionen zu generieren und so die Integration mit externen Tools und APIs zu ermöglichen.

:::note[Voraussetzungen]
- Ein API-Schlüssel ([hier erhalten](https://apikey.llmhub.t-systems.net/))
- OpenAI SDK installiert ([Quickstart](/de/getting-started/quickstart))
- Ein Modell, das Function Calling unterstützt (die meisten gehosteten Modelle tun das — siehe [Verfügbare Modelle](/de/models))
:::

**Was Sie lernen werden:**
- Wie Sie Tools/Funktionen definieren, die das Modell aufrufen kann
- Wie Sie Function Calling mit der Responses API verwenden
- Wohin das JSON-Schema-Beispiel gezogen ist ([Strukturierte Ausgaben](/de/guides/structured-outputs))


## Einfaches Beispiel

<Tabs>
  <TabItem value="python" label="Python" default>
    ```python showLineNumbers
    from openai import OpenAI

    client = OpenAI()

    tools = [
        {
            "type": "function",
            "function": {
                "name": "get_current_weather",
                "description": "Get the current weather",
                "parameters": {
                    "type": "object",
                    "properties": {
                        "location": {
                            "type": "string",
                            "description": "The city and state, e.g. San Francisco, CA",
                        },
                        "format": {
                            "type": "string",
                            "enum": ["celsius", "fahrenheit"],
                            "description": "The temperature unit to use.",
                        },
                    },
                    "required": ["location", "format"],
                },
            },
        },
    ]

    messages = [
        {"role": "system", "content": "Don't make assumptions about what values to plug into functions. Ask for clarification if a user request is ambiguous."},
        {"role": "user", "content": "What's the weather like today in Hamburg?"},
    ]

    response = client.chat.completions.create(
        model="GLM-5.3",
        messages=messages,
        tools=tools,
    )

    print(response.choices[0].message)
    ```

## Function Calling mit der Responses API

```python showLineNumbers
from openai import OpenAI

client = OpenAI()

tools = [
    {
        "type": "function",
        "name": "get_weather",
        "description": "Get current temperature for a given location.",
        "parameters": {
            "type": "object",
            "properties": {
                "location": {
                    "type": "string",
                    "description": "City and country e.g. Bogota, Colombia",
                }
            },
            "required": ["location"],
            "additionalProperties": False,
        },
    }
]

response = client.responses.create(
    model="GLM-5.3",
    input=[{"role": "user", "content": "What is the weather like in Paris today?"}],
    tools=tools,
)

print(response.output)
```

## Grenzen und Fehlersuche

:::note
Function Calling funktioniert mit einer breiten Auswahl an Modellen auf der Plattform — darunter Modelle von OpenAI, Google und Anthropic sowie viele Open-Source-Modelle. Die in diesem Guide verwendeten Modellnamen sind lediglich Beispiele und nicht die einzigen Modelle, die die Funktion unterstützen. Einige auf T-Cloud gehostete Open-Source-Modelle unterstützen Function Calling noch nicht; prüfen Sie den Eintrag des Modells unter [Verfügbare Modelle](/de/models), bevor Sie sich darauf verlassen.

Auch die Responses API ist nicht auf OpenAI-Modelle beschränkt — Tool Calls darüber sind ebenso für Google-, Anthropic- und T-Cloud-gehostete Open-Source-Modelle bestätigt, einzelne Modelle weisen Responses-API-Anfragen allerdings noch zurück.
:::
