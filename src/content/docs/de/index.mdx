Die souveräne KI-Plattform von <span class="nowrap">T-Systems</span>: über 30 Open-Source- und proprietäre Modelle hinter einer OpenAI-kompatiblen API.

- Open-Source-Modelle laufen auf T-Cloud in Deutschland, innerhalb der EU.
- Ihre Prompts werden nicht zum Training von Modellen verwendet.
- Die API ist OpenAI-kompatibel: Basis-URL und Schlüssel setzen.


## Modelle

Wenn ein T-Cloud-Modell zur Aufgabe passt, beginnen Sie dort. Partnermodelle von OpenAI, Anthropic und Google liegen auf derselben API.

## Quickstart

API-Schlüssel holen, zwei Umgebungsvariablen setzen, erste Anfrage senden: Der [Quickstart](/de/getting-started/quickstart) braucht drei Schritte, mit Beispielen für curl, Python und Node.js. Lieber eine Oberfläche? Nutzen Sie den [Playground](https://playground.llmhub.t-systems.net/). Sie richten ein Coding-Tool ein? Siehe [Coding-Agenten einrichten](/de/getting-started/coding-agents).
