## Erste Anfrage

<Steps>

1. OpenAI-Paket installieren.

   ```bash
   pip install openai
   ```

2. Eine Chat-Completion an die Basis-URL senden.

   ```bash
   curl -X POST "https://llm-server.llmhub.t-systems.net/v2/chat/completions" \
     -H "Authorization: Bearer $OPENAI_API_KEY" \
     -H "Content-Type: application/json" \
     -d '{
       "model": "gpt-oss-120b",
       "messages": [{"role": "user", "content": "Hello"}]
     }'
   ```

3. Schlüssel, Umgebungsvariablen und Node.js stehen im [Quickstart](/de/getting-started/quickstart).

</Steps>
