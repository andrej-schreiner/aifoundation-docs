Major changes to AI Foundation Services — new models, feature updates, and deprecations.

Entries follow [Keep a Changelog](https://keepachangelog.com/) and [Semantic Versioning](https://semver.org/) conventions. Within each release, items are grouped under `### Added`, `### Changed`, `### Deprecated`, `### Removed`, or `### Fixed` subheadings.

## Versioning policy

- **Major** (`vX.0.0`) — breaking API changes (endpoint removed, request/response schema changed in an incompatible way, authentication scheme replaced).
- **Minor** (`vX.Y.0`) — model added or removed, plan added or removed, new feature or endpoint, schedule-for-retirement changes.
- **Patch** (`vX.Y.Z`) — copy fixes, accessibility, typos, link corrections, behind-the-scenes refactors.

Each release is archived under `/v<version>/` so older snapshots stay accessible after the live docs move on.
