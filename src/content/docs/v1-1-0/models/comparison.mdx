## Understanding Model Categories

- **Chat & Reasoning (LLMs)** — General-purpose text generation, conversational agents, and reasoning. Most accept multilingual input.
- **Coding** — Code-tuned models for completion, refactoring, and review. Stronger on programming benchmarks than general LLMs of similar parameter count.
- **Vision** — Multimodal models that accept image input alongside text. Use the same Chat Completions endpoint.
- **Embeddings** — Convert text to vectors for semantic search, clustering, and RAG.
- **Audio (Speech-to-Text)** — Whisper-family models for transcription and translation.
- **Image Generation** — Generate images from text prompts (and optionally an input image).

For sovereignty and data-handling details, see [Enterprise Trust](/reference/enterprise-trust).
