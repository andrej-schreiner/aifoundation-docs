## Quickstart

Send a first request in three steps. Prefer a UI? Use the [Playground](https://playground.llmhub.t-systems.net/).

### 1. Get an API key

Create a free trial key in the [API Key Portal](https://apikey.llmhub.t-systems.net/). A trial key unlocks all models, including Premium models. For a production plan, [contact us](mailto:ai@t-systems.com).

### 2. Set two environment variables

<Tabs>
  <TabItem value="mac" label="macOS/Linux" default>
    ```bash
    export OPENAI_API_KEY="your_api_key_here"
    export OPENAI_BASE_URL="https://llm-server.ai.t-systems.net/v1"
    ```
  </TabItem>
  <TabItem value="windows-ps" label="PowerShell">
    ```powershell
    $env:OPENAI_API_KEY = "your_api_key_here"
    $env:OPENAI_BASE_URL = "https://llm-server.ai.t-systems.net/v1"
    ```
  </TabItem>
  <TabItem value="windows-cmd" label="CMD">
    ```bash
    setx OPENAI_API_KEY "your_api_key_here"
    setx OPENAI_BASE_URL "https://llm-server.ai.t-systems.net/v1"
    ```
  </TabItem>
</Tabs>

### 3. Send a request

<Tabs>
  <TabItem value="curl" label="curl" default>
    ```bash
    curl -X POST "$OPENAI_BASE_URL/chat/completions" \
      -H "Authorization: Bearer $OPENAI_API_KEY" \
      -H "Content-Type: application/json" \
      -d '{
        "model": "gpt-oss-120b",
        "messages": [{"role": "user", "content": "Hello from AIFS"}]
      }'
    ```
  </TabItem>
  <TabItem value="python" label="Python">
    ```python
    # pip install openai
    from openai import OpenAI

    client = OpenAI()
    response = client.chat.completions.create(
        model="gpt-oss-120b",
        messages=[{"role": "user", "content": "Hello from AIFS"}],
    )
    print(response.choices[0].message.content)
    ```
  </TabItem>
  <TabItem value="node" label="Node.js">
    ```javascript
    // npm install openai
    import OpenAI from "openai";

    const client = new OpenAI();
    const response = await client.chat.completions.create({
      model: "gpt-oss-120b",
      messages: [{ role: "user", content: "Hello from AIFS" }],
    });
    console.log(response.choices[0].message.content);
    ```
  </TabItem>
</Tabs>

## Plans

The minimum is a monthly token revenue commitment. Usage above it is billed at list prices. Plans differ by throughput (TPM and RPM) and by Premium model access. Premium models such as Claude are included on Professional and Agentic, not on Essential.

- **Essential** — €1,000 / month. Standard catalog. Lower throughput.
- **Professional** — €3,000 / month. Premium models included. Medium throughput.
- **Agentic** — €5,000 / month. Premium models included. Highest best-effort throughput.
- **Enterprise** — Custom token commitment and custom rate limits. The pricing catalog has no separate Enterprise model list.
