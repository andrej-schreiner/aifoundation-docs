## Quickstart

Get up and running in minutes: install the OpenAI SDK, set your API key, and send a first request. Prefer to click rather than curl? Try the [LLM Playground](https://playground.llmhub.t-systems.net/).

## 1. Install the OpenAI package

AI Foundation Services uses an OpenAI-compatible API, so you can use the official OpenAI SDKs.

<Tabs>
  <TabItem value="python" label="Python" default>
    ```bash
    pip install openai
    ```
  </TabItem>
  <TabItem value="node" label="Node.js">
    ```bash
    npm install openai
    ```
  </TabItem>
</Tabs>

## 2. Get an API key

Get a free trial key in the [API Key Portal](https://apikey.llmhub.t-systems.net/). For production workloads, [contact us](mailto:ai@t-systems.com).

## 3. Set environment variables

<Tabs>
  <TabItem value="mac" label="macOS / Linux" default>
    ```bash
    export OPENAI_API_KEY="your_api_key_here"
    export OPENAI_BASE_URL="https://llm-server.llmhub.t-systems.net/v2"
    ```
  </TabItem>
  <TabItem value="windows-ps" label="Windows (PowerShell)">
    ```powershell
    [System.Environment]::SetEnvironmentVariable('OPENAI_API_KEY', 'your_api_key_here', 'User')
    [System.Environment]::SetEnvironmentVariable('OPENAI_BASE_URL', 'https://llm-server.llmhub.t-systems.net/v2', 'User')
    ```
  </TabItem>
  <TabItem value="windows-cmd" label="Windows (CMD)">
    ```bash
    setx OPENAI_API_KEY "your_api_key_here"
    setx OPENAI_BASE_URL "https://llm-server.llmhub.t-systems.net/v2"
    ```
  </TabItem>
</Tabs>

## 4. Make your first API call

<Tabs>
  <TabItem value="curl" label="curl" default>
    ```bash
    curl -X POST "$OPENAI_BASE_URL/chat/completions" \
      -H "Authorization: Bearer $OPENAI_API_KEY" \
      -H "Content-Type: application/json" \
      -d '{
        "model": "gpt-oss-120b",
        "messages": [{"role": "user", "content": "Hello from AIFS"}]
      }'
    ```
  </TabItem>
  <TabItem value="python" label="Python">
    ```python
    from openai import OpenAI

    client = OpenAI()

    response = client.chat.completions.create(
        model="gpt-oss-120b",
        messages=[{"role": "user", "content": "Hello from AIFS"}],
    )
    print(response.choices[0].message.content)
    ```
  </TabItem>
  <TabItem value="node" label="Node.js">
    ```javascript
    import OpenAI from "openai";

    const client = new OpenAI();

    const response = await client.chat.completions.create({
      model: "gpt-oss-120b",
      messages: [{ role: "user", content: "Hello from AIFS" }],
    });
    console.log(response.choices[0].message.content);
    ```
  </TabItem>
</Tabs>

## Try a capability

The same client and base URL. Try streaming, tools, structured output, reasoning, and image input.

### Streaming

<Tabs>
  <TabItem value="curl" label="curl" default>
    ```bash
    curl -X POST "$OPENAI_BASE_URL/chat/completions" \
      -H "Authorization: Bearer $OPENAI_API_KEY" \
      -H "Content-Type: application/json" \
      -d '{
        "model": "gpt-oss-120b",
        "messages": [{"role": "user", "content": "Explain quantum computing"}],
        "stream": true
      }'
    ```
  </TabItem>
  <TabItem value="python" label="Python">
    ```python
    stream = client.chat.completions.create(
        model="gpt-oss-120b",
        messages=[{"role": "user", "content": "Write a short poem about AI."}],
        stream=True,
    )
    for chunk in stream:
        if chunk.choices and chunk.choices[0].delta.content:
            print(chunk.choices[0].delta.content, end="", flush=True)
    ```
  </TabItem>
  <TabItem value="node" label="Node.js">
    ```javascript
    const stream = await client.chat.completions.create({
      model: "gpt-oss-120b",
      messages: [{ role: "user", content: "Write a short poem about AI." }],
      stream: true,
    });
    for await (const chunk of stream) {
      const text = chunk.choices[0]?.delta?.content;
      if (text) process.stdout.write(text);
    }
    ```
  </TabItem>
</Tabs>

Full streaming notes: [Streaming](/guides/streaming).

### Function calling

Call a tool with `GLM-5.3`.

<Tabs>
  <TabItem value="python" label="Python" default>
    ```python
    response = client.chat.completions.create(
        model="GLM-5.3",
        messages=[{"role": "user", "content": "What's the weather like today in Hamburg?"}],
        tools=[{
            "type": "function",
            "function": {
                "name": "get_current_weather",
                "description": "Get the current weather",
                "parameters": {
                    "type": "object",
                    "properties": {
                        "location": {"type": "string"},
                        "format": {"type": "string", "enum": ["celsius", "fahrenheit"]},
                    },
                    "required": ["location", "format"],
                },
            },
        }],
    )
    print(response.choices[0].message)
    ```
  </TabItem>
</Tabs>

### Structured output

JSON that matches a schema, on the Responses API. Check that your model supports `text.format` with `json_schema` before relying on it. See [Structured outputs](/guides/structured-outputs).

<Tabs>
  <TabItem value="python" label="Python" default>
    ```python
    response = client.responses.create(
        model="gpt-oss-120b",
        input="Extract structured product information: Premium Laptop Backpack, $79.99.",
        text={
            "format": {
                "type": "json_schema",
                "name": "product_details",
                "schema": {
                    "type": "object",
                    "properties": {"product_name": {"type": "string"}},
                    "required": ["product_name"],
                    "additionalProperties": False,
                },
                "strict": True,
            }
        },
    )
    print(response.output_text)
    ```
  </TabItem>
</Tabs>

### Reasoning effort

The datasheet lists `low`, `medium`, and `high` for `gpt-oss-120b`. Other models publish a different list. See [Reasoning](/guides/reasoning).

<Tabs>
  <TabItem value="python" label="Python" default>
    ```python
    response = client.chat.completions.create(
        model="gpt-oss-120b",
        messages=[{"role": "user", "content": "What is the capital of France?"}],
        reasoning_effort="low",
    )
    print(response.choices[0].message.content)
    ```
  </TabItem>
</Tabs>
