## First request

<Steps>

1. Install the OpenAI package.

   ```bash
   pip install openai
   ```

2. Send a chat completion to the AI Foundation base URL.

   ```bash
   curl -X POST "https://llm-server.llmhub.t-systems.net/v2/chat/completions" \
     -H "Authorization: Bearer $OPENAI_API_KEY" \
     -H "Content-Type: application/json" \
     -d '{
       "model": "gpt-oss-120b",
       "messages": [{"role": "user", "content": "Hello"}]
     }'
   ```

3. API keys, environment variables, and Node.js are in the [Quickstart](/getting-started/quickstart).

</Steps>
