The sovereign AI platform from <span class="nowrap">T-Systems</span>: 30+ open-source and proprietary models behind one OpenAI-compatible API.

- Open-source models run on T-Cloud in Germany, within the EU.
- Your prompts are not used to train models.
- The API is OpenAI-compatible: set a base URL and a key.
